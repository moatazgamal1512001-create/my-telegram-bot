# Moataz Selfie Bot — starter

## طريقة التشغيل
1. أنشئ بوتاً عبر BotFather وخذ BOT_TOKEN.
2. انشر المشروع على استضافة تدعم Python وHTTPS (الكاميرا في المتصفح تحتاج HTTPS أو localhost).
3. اضبط متغيري البيئة:
   - `BOT_TOKEN`: توكن البوت.
   - `PUBLIC_BASE_URL`: رابط موقعك العام مثل `https://example.com` بدون `/` في النهاية.
4. ثبّت المتطلبات: `pip install -r requirements.txt`
5. شغّل: `python bot.py`
6. افتح البوت واضغط `/start` للحصول على رابط جلسة.

## السلوك والخصوصية
- لا يبدأ تشغيل الكاميرا إلا بعد ضغط الزائر على زر تشغيل الكاميرا وقبول نافذة المتصفح.
- لا يلتقط أو يرسل شيئاً تلقائياً؛ الزائر يختار الصورة/الفيديو ويضغط إرسال بنفسه.
- يجب إبلاغ الشخص بوضوح أن الملف سيُرسل إلى صاحب رابط الدعوة.

## ملاحظات تقنية
- هذا نموذج أولي للتجربة. الجلسات محفوظة في الذاكرة وتُفقد عند إعادة تشغيل التطبيق.
- استخدم قاعدة بيانات وتخزين جلسات آمن قبل الاستخدام الفعلي، وأضف تحديد حجم الملفات ومعدل الطلبات.
- الفيديو يتضمن صوتاً إذا وافق المستخدم على إذن الميكروفون. يمكن حذف `audio:true` إذا لم تكن تحتاج الصوت.
- لا تضع التوكن داخل الكود أو تشاركه مع أي شخص.
